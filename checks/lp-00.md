# LP-0 — On-Mac spikes

**Status: not run.** Every spike needs the owner's real Mac with Latch
connected, and this work was done in a cloud container without one. Nothing
below has been observed yet. The code written after this file assumes the
answers in the "Assumed" column and keeps each assumption in one constant, so
that a different answer is a one-place change.

| Spike | Question | Assumed until measured | Where the assumption lives |
|---|---|---|---|
| S1 | `plow-gog gmail search "in:sent newer_than:2d" --max 25 --json` twice: is the second approval remembered? Which fields come back (`to`, `cc`, `snippet`, `body`)? Thread or message per row? | Remembered (fixed argv). Rows may be threads or messages; `to`, `snippet` and `body` may be missing. | `skills/loop/scripts/scan-mail.ts` (`SENT_ARGV`, `parseMailRows`) |
| S2 | Can the body be read with a remembered approval (`gmail thread get <id>` with a variable id, or a fixed-argv flag)? | No. The scheduled scan uses whatever text the search returns (subject + snippet/body when present) and reports `degraded: ["mail-no-body"]` when a row has no body. Full threads are read only with the owner present (backfill, DM turns). | `scan-mail.ts` |
| S3 | Does `plow-messages search --limit 200 --order desc` (read_paths `~/Library/Messages`) return `is_from_me=1` rows? Do group chats come with a distinct `chat_identifier`? | Yes to both. Group rows are skipped in v0.1. | `skills/loop/scripts/scan-imessage.ts` (`SEARCH_ARGV`, `parseMessageRows`) |
| S4 | Does `plow-gog gmail drafts create` exist, reply in a thread, and need approval each time? | Exists, takes `--to`, `--subject`, `--body`, `--reply-to-message-id`; asks each time (the owner is present when a draft is made). | S5 | Does `contacts` return a person's name and every phone/email in one call with a fixed argv? | Not relied on. People are matched by exact handle only; the Mac's contacts are an optional lookup. | `skills/loop/scripts/people.ts` |
| S6 | Can an isolated `openclaw cron` job DM the owner with `message send` + `owner-chat.ts` on 2026.9.6? | Yes (Meetly does it on the same release). | `skills/loop-poll/SKILL.md`, `skills/loop-digest/SKILL.md` |
| S7 | Is `node:sqlite` available with WAL in the pinned image, and does `/var/lib/plow` take the lock file? | Yes. Measured locally on Node 24.21.0 (the tests open the ledger in WAL mode); the image's own Node still to be checked. | `skills/loop/scripts/db.ts` |

## Review gate

S1 and S2 decide whether the scheduled scan can detect commitments in email at
all. If S1 shows no remembered approval, or S2 shows that bodies can never be
read unattended, D2/D8 have to be revisited before relying on the mail scan
(iMessage and the owner's own "anota: …" notes still work).

To run them: on the owner's Mac, from a Plow DM turn with Latch connected, run
each command twice and record the exact output and whether Latch asked again.
