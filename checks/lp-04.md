# LP-4 — Cron jobs

## What changed

- `skills/loop/scripts/register-crons.ts` + `cron-backend.ts` (Meetly's, with
  cron-expression schedules): `loop-poll` every 15 minutes; `loop-digest` daily
  at `config.digestTime` in `config.timezone` (`--cron "M H * * *" --tz <zone>
  --exact`, so it is not staggered away from the owner's minute). Idempotent,
  `loop-` prefix only, drift edited in place, never remove-then-create.
- `record-setup.ts` registers the jobs on `--done`, `--pause`, `--resume`, and
  when `digestTime` or `timezone` changes. Pausing disables both jobs.
- `LOOP_OPENCLAW_CLI` lets the tests replace `/app/openclaw.mjs` with
  `tests/fixtures/fake-openclaw.mjs`, so the CLI path is exercised end to end.
- `skills/loop-poll`, `skills/loop-digest`: the scheduled turns' skills. For
  now each only checks setup/pause and ends silently; the scan (LP-5 on) and
  the digest (LP-10) fill them.
- The prompt routes `Loop poll.` / `Loop digest.` turns to those skills.

The `cron add` flags (`--cron`, `--tz`, `--exact`, `--every`, `--session`,
`--message`, `--timeout-seconds`, `--no-deliver`, `--disabled`) and the
schedule shape `{kind:"cron", expr, tz}` were read from the pinned
`openclaw@2026.9.6` CLI (`dist/cron-cli-*.mjs`).
