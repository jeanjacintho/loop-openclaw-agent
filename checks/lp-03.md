# LP-3 — Setup and setup gate

## What changed

- `skills/loop/scripts/config.ts`, `setup-status.ts`, `record-setup.ts`: four
  questions in order (`ownerName`, `timezone`, `digestTime`, `sources`), the
  first two filled by themselves from the Plow profile and the Mac
  (`mac-timezone.ts`); `language` and `domainRoles` can be set at any time and
  are never asked. `--pause` / `--resume` flip `paused`. State in
  `/var/lib/plow/loop/config.json` (atomic JSON + lock: `store.ts`, Meetly's).
- `setup-status.ts` READY also gives the owner's local `now` and `weekday`,
  so every owner turn knows what "today" is.
- `gate/`: Meetly's setup gate with Loop's words. Loaded by the fork's boot
  config beside the channel plugin (`plugins.load.paths` gains
  `/opt/plow/gate`, `plugins.entries.loop` with `allowConversationAccess`),
  both Plow-owned includes, so the owner's config cannot drop them.
- `boot/config.ts`: the Mac relay gets `requestTimeoutMs: 60000` (Meetly's
  fix: without it OpenClaw caps the relay's tool listing at 1500 ms).
- `skills/loop/scripts/mac.ts`: `callMac` says why a Mac command gave nothing
  (`no-bridge`, `unreachable`, `blocked` with Latch's `owner_action`,
  `refused`, `failed`); `runOnMac` keeps Meetly's shape.
- `owner-chat.ts`, `time.ts`, `mac-timezone.ts`: copied from Meetly.
- `skills/loop-setup/SKILL.md`, the owner-DM routing in the prompt.

## Deferred on purpose

- The source probe with the scan's exact argv ("the owner approves 'always'
  now") is added to `loop-setup` with the scanners (LP-5), which own that argv.
- "Can I look at the last two weeks now?" is added with the backfill (LP-13).
- Registering the cron jobs on `--done` and on pause/resume comes with LP-4.
